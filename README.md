# Stock Checker - Simple Inventory Tracker

## About My Project
This is a simple inventory tracker I made using Java. It helps a small store keep track of products and their quantities.

## Features
1. Add a new product and its quantity.
2. View all products in the inventory.
3. Check which products are low in stock.
4. Update the quantity of a product.
5. Remove a product from the inventory.
6. Exit the program.

## How to Run
1. Download all three Java files.
2. Save them in the same folder.
3. Open StockChecker.java in jGRASP.
4. Compile and run the program.
5. Choose an option from the menu.

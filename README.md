# Stock Checker - Simple Inventory Tracker

## About My Project
This is a simple inventory tracker I made using Java. It helps a small store keep track of products and their quantities.

## Features
1. Add a new product and its quantity.
2. View all the products in the inventory.
3. Check which products are low in stock.
4. Exit the program.

## How to Run
1. Download the StockChecker.java file.
2. Open it in jGRASP or another Java program.
3. Compile and run the code.
4. Choose an option from the menu.

## Tools Used
- Java
- jGRASP
- GitHub
